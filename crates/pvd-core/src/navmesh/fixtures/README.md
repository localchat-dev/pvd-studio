# Independent Detour fixture

`recast-0.43.1.bin` is generated by the installed upstream
`@recast-navigation/core`, `generators` and `wasm` packages, all version 0.43.1.
It is a synthetic 10 × 10 plane, not a user map. The JSON contains triangle
positions independently extracted by upstream after an export/import round trip.
The Rust test compares every rendered triangle corner against those positions.

Regenerate, optionally, using `node generate.mjs PATH_TO_NODE_MODULES` from this
directory. This is a development check only; the application has no Node/WASM
dependency. The script verifies package versions before generating data.

The emitted binary confirms MSET v1, little endian, 32-bit tile references,
DNAV v7 with six polygon slots, header sizes 40/8/100 bytes and record sizes:
polygon 32, link 12, detail mesh 12, BV node 16, off-mesh connection 36.
Field definitions agree with the upstream Detour documentation:
https://recastnav.com/DetourNavMesh_8h_source.html

Compatibility evidence is limited to the 0.43.1 importer and exporter round
trip. It does not establish compatibility with other `.bin` layouts or every
tagged C++ importer.

`synthetic-detail.bin` and `.json` come from
`tools/navmesh/create-fixture.py`. They cover two tiles, extra detail vertices,
slopes and an off-mesh connection. Their expected triangles were separately
checked with the installed 0.43.1 WASM importer/extractor; they do not claim
production Unity export compatibility.
