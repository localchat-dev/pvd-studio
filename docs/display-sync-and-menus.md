# 显示过滤、来源索引与设置菜单

## 显示语义与预算

静态、动态、休眠或运动学过滤只影响可见性。隐藏对象继续参与依赖索引；位姿、形状、几何、Articulation 父级及代际变化照常更新，再次显示时使用当前帧。设置、选择、坐标变更、revision 缺口和换源触发完整重建；无效几何或资源拒绝保留回退。

显示预算按全部来源形状计量，包含隐藏对象：最多 100,000 个形状、128 MiB 共享几何。更新先扣除受影响 Actor 的旧资源，再核对替换后的总量。共享几何在最后一个来源用户消失后退出预算；隐藏对象保留共享数组，保证指针键有效。

几何字节按顶点数 × 12 + 索引数 × 4 计量，同一共享数组对只算一次。它不是进程内存、GPU 内存或数组预留容量的总上限。

## 来源索引

`SourceIndex` 保存按 ID 排序的 Scene、Cloth、Particle 来源集合，不以 Actor 可见性筛选。完整更新或变更范围缺失时重建；增量先移除变化 ID，再按最终对象类型加入，覆盖同批创建/销毁、换类型和 ID 复用。三个集合合计最多 100,000 个 ID，越限时清空并回退到完整收集，状态缩小时可恢复。

索引只缩短查找。每次显示仍从当前 `SceneState` 解码，保留 Fabric、查询几何/代际引用、粒子属性等间接更新和诊断，不缓存过期的解码结果。桌面的 50,000 点、100,000 条 Fabric 边等显示边界独立保留。

`SceneChanges` 每次只取一次：来源索引先借用变化集合，Actor 同步再消费。来源提取及诊断在 Actor 增量返回之前完成。

## 设置菜单

录制设置、图页设置、选中 Actor RepX 和整帧 RepX 支持连续编辑。点击文本框、数值或复选框保持菜单；点击外部、Escape 或完成明确动作后关闭。此行为仅作用于对应应用菜单，不修改 egui 的全局默认。

## 验证要求

过滤和来源索引需要与强制全量路径比较，覆盖隐藏更新、父链变化、销毁/复用、重新显示、设置变更、revision 缺口、共享资源和预算恢复。Cloth、粒子、查询使用独立 SDK 真值；索引与完整收集的输出顺序及诊断应一致。

CPU 微测量需排除历史恢复、补丁应用、核对和 GPU 成本，并分别记录索引维护、完整重建和增量显示。它不代表完整窗口帧率。菜单的 egui 事件测试不能替代原生保存对话框、IME、DPI 与完整停靠验收，相关缺口见[路线图](roadmap.md)。
