# 正常退出与临时文件

关闭主窗口时，应用先请求停止接收、加载、回放和导出，再等待后台任务释放资源，最后退出。等待期间显示收尾提示，不能启动新的录制或后台任务。切换录制后仍在收尾的任务也属于同一应用实例。

网络接收、历史读取、文件载入、曲线/性能查询、片段定义保存和采样 CSV/RepX 写出注册到每个 Studio 的任务集合，最多 128 项；完整录制、流式片段和完整分析导出另有每实例最多 2 项的许可集合。资源析构完成后才撤销任务标记。取消回调在注册表锁之外执行，不持锁等待网络或磁盘。

导出先写目标目录的暂存文件，完成写入、同步和取消检查后才发布。失败或取消清理自己的暂存文件，不覆盖已存在的目标。已发布结果不会因随后关闭窗口而被删除。文件选择对话框不持有录制或历史文件，不计入收尾等待。

这些保证适用于正常关闭。强制终止、断电和磁盘故障可能留下临时文件。永久原始录制 `.pvdstream/.partial` 与临时缓存独立，不随缓存清理而删除。

## 验证

退出专项覆盖监听待连接、接收积压、历史定位、旧接收任务与新加载并存，以及磁盘文件加载。父进程等待子进程真正结束后检查缓存，不能额外清理文件来制造通过结果。

指定至少 32 MiB 的真实 SDK 流及新的输出目录后执行：

```powershell
$env:PVD_EXIT_PROBE_CAPTURE = '<真实 SDK 流的绝对路径>'
$env:PVD_EXIT_PROBE_OUTPUT = '<新的输出目录的绝对路径>'
cargo test --locked --release -p pvd-desktop studio::shutdown_tests::real_tcp_process_exit_releases_history_and_receive_files -- --exact --ignored --nocapture --test-threads=1
```

`--render-check` 的成功、截图保存失败、缺少相机和超时出口等待相同的收尾流程。第一终止原因保持不变，迟到的截图不能把超时变为成功。此入口不写用户布局；正常退出后应检查缓存释放、返回码和原输入摘要。离屏结果不替代原生窗口验收。
