# 实现路线图

参考目标为 NVIDIA PhysX Visual Debugger 3（PVD3）的功能与工作流程。主要验证路径为 PhysX 3.4.2；其他 SDK、APEX 和 GPU 数据按独立范围建立证据。OmniPVD/`.ovd` 属于单独的兼容方向。

本计划区分缺少实现与缺少验证。优先级表示推进顺序，不表示完成日期；范围、依赖或证据变化时同步更新[功能清单](manual-checklist.md)和[兼容矩阵](compatibility.md)。

功能概况见[项目状态](current-status.md)。本文维护未完成工作的稳定编号和完成条件。

## P0：原版文件完整工作流

| 编号 | 当前边界 | 工作与完成条件 |
| --- | --- | --- |
| FILE-01 | `.pxd2` 写出只有独立前缀实验，未接正式入口 | 实现受支持布局的正式保存，明确版本和拒绝范围；通过 PVD3 打开、正倒放、重存，并核对对象、帧和分析 |
| FILE-02 | 原版任意区间裁剪未实现 | 从中段重建必要的对象/资源初始状态、目录和历史；原版重开后首帧及后续状态与源区间一致，不补造缺失分析历史 |
| FILE-03 | 非空 event=0 初始快照、多页遍历已有代码，缺少真实原版配对 | 取得有来源的多页和非空起点容器、同次原始流及独立真值，覆盖正倒/随机恢复、引用、保存实例和截断边界 |
| FILE-04 | 原版导入整文件读入，超过 512 MiB 明确拒绝 | 接入有界随机读取及磁盘历史；使用真实大型原版文件验证目录/页读取、取消、资源预算和状态一致性 |
| FILE-05 | 旧 `.pxd` 及原版过滤器中的 `.pvd` 尚无兼容证据 | 取得可追溯样例并识别格式/版本；每种布局独立实现和配对验证，不以扩展名判断 |

原版写出实验见[前缀实验](native-prefix-experiment.md)，读取边界见[容器说明](original-file-format.md)。构造输入和自读测试只覆盖实现分支，不能替代原版互通。

## P1：数据、显示与导出

| 编号 | 当前边界 | 工作与完成条件 |
| --- | --- | --- |
| DATA-01 | 原版通信目录的相机和显示设置未导入 | 按已确认字段恢复设置，覆盖空/非空目录及生命周期；与原版实际保存和显示对照 |
| DATA-02 | 原版点/线/文本/非空批量绘制已有解析路径，真实配对不足 | 生成对应原版容器，验证多次提交、空帧、renderer 重建、多 Scene 和正倒/随机状态 |
| DATA-03 | OriginShift 已覆盖固定 3.4.2 对象；查询/接触/已有绘制坐标语义待建立 | 以 SDK getter/缓冲及原版样例确认每个坐标域的归属与更新规则，再实现和验证；不猜测相机所属 Scene |
| DATA-04 | RepX 覆盖刚体、受支持 Shape/资源及六类官方关节 | 分别调查 Aggregate、Articulation、Cloth、Particle、特殊约束、运动学目标和单 Actor 关节依赖；对可恢复对象实现 SDK 导入及逐属性核对，缺失源数据明确拒绝 |
| DATA-05 | 其他 SDK、APEX/GPU 及特殊类型未建立完整范围 | 按版本和类别取得真实输出，核对布局、生命周期、几何、分析和文件/TCP 两条路径；不从共用源码外推兼容 |

CPU Cloth 目前显示捕获的点和 Fabric 约束；样例缺少表面拓扑与 solver previousParticles。CPU ParticleSystem/Fluid 显示粒子点，不重建流体表面。这类来源限制须与实现缺口分别记录。

## P2：产品与规模验收

| 编号 | 当前边界 | 工作与完成条件 |
| --- | --- | --- |
| PRODUCT-01 | 部分英文和录制相机离屏图存在顶部绘制缺失，原生交互覆盖不完整 | 定位并修复工具栏绘制缺失；补齐文件/保存对话框、剪贴板、引用跳转、曲线操作、标签停靠、动态 DPI、其他 IME 和焦点路径 |
| PRODUCT-02 | 本地真实回环与有限长跑已有记录，用户远端场景未验收 | 在真实跨机器负载下同时接收和正倒放，分别记录解析、模型提交、GPU 完成、积压及历史窗口；保持真值和退出清理检查 |
| PRODUCT-03 | 长期资源趋势未完成 | 重复连接、打开/关闭、取消和错误恢复，测量进程/GPU 资源、缓存残留与句柄趋势；验证滚动历史和磁盘余量边界 |
| PRODUCT-04 | 尚无完整的原版同输入性能对照 | 固定机器、输入、保留范围和显示设置，分别测量冷定位、热步进、持续接收和原生显示；不混算 API 耗时与帧率 |
| PRODUCT-05 | 手册中的任意上轴/自动判断、帮助与版本入口缺失；选择手势、配色、图页和部分设置行为不同 | 按手册第 6–11 页核对操作；补齐上轴和帮助入口，明确等价操作与需一致的行为，逐项验收。项目帮助及问题渠道使用本项目资料 |

自动化优先使用 CLI、真实 SDK 和无窗口渲染。操作系统输入、DPI 与原版打开互通只在对应环境中验收；自动化不能覆盖时明确保留待验状态。

## 完成规则

1. 实现有明确的数据来源、格式/版本边界、错误行为和资源限制。
2. 记录输入身份、源码或提交身份、实际命令和结果；忽略项与失败记录单列。
3. 同帧对象、属性、引用、分析与显示保持一致，错误/取消不发布半成品。
4. 格式声明需要外部交叉验证；文件原版可打开不等于全部语义一致。
5. 提交说明记录已经落地的变化和当前限制，完整后续计划在本文维护。
