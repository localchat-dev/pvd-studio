# Unity Scene 视图

插件由 Windows x64 原生接收库和 Unity Editor 包组成。分发包包含 DLL，使用设备只需要 Unity 编辑器。源码包声明的最低编辑器版本为 2022.3。

## 安装与监听

在构建机的仓库根目录运行以下命令。脚本输出含原生 DLL 的 UPM 压缩包和已展开的包目录。在使用设备的 Unity Package Manager 加号菜单选 **Add package from tarball**，打开 `.tgz`。也可以复制整个展开目录，选 **Add package from disk** 打开包中的 `package.json`。

```powershell
./tools/package-unity.ps1
```

在 **Tools → PVD Studio** 打开插件窗口，在「监听设置」中配置地址，然后点击「开始监听」。PhysX 发送端连接编辑器机器可达的地址及同一端口。Scene 视图叠加捕获的刚体形状；编辑器窗口无需放置到游戏场景，游戏切换场景时继续使用同一 TCP 会话。使用多物理场景的地图，可以在「叠加显示」里选择显示范围。

折叠设置时，下方的内容会上移。插件作为独立浮窗时还会从底边收短。展开时，如果高度不够，会在当前屏幕的可用空间内增高，其余内容可滚动查看。停靠或最大化时，只调整窗口内的布局。

从 0.2.1 或更早版本升级前，先在 **Tools → PVD Studio** 点 **停止监听**。若已更新且端口仍被该 Unity 编辑器占用，保存工程并完整退出该编辑器，重新打开后再开始监听。

从 0.2.2 开始，Package Manager 替换或移除本包前，插件会关闭 TCP 连接、释放监听端口并结束本次临时录制与回放。更新完成后手动开始监听，让发送端重新连接。若升级同时更换了已加载的原生 DLL，重启 Unity 后使用新版 DLL。普通脚本重载和游戏切图可继续使用原监听。

默认仅实时查看。会话选择框右侧显示已绘制的帧号，悬停可查看已接收的帧数和完整录制说明。插件按序解码，保留最新完整帧。关闭插件窗口时监听继续，重新打开即可查看最新帧。断开后释放该会话。Unity 地图与相机来自当前编辑器场景。

需要暂停 PVD 画面、逐帧回看或导出时，在开始监听前进入「监听设置」，勾选「完整录制」。这个模式保留本次会话的历史，包括窗口关闭期间收到的完整帧。断开后仍可选择已结束的完整录制，在编辑器退出前查看。

完整录制的显示帧和时间轴位于「会话」下方。时间轴从第 0 帧起算，拖动后会显示目标帧，定位期间可取消并保留当前画面。按钮支持暂停、逐帧、正放、倒放和返回实时。接收和完整录制在回看时继续进行。

收到含可显示碰撞形状的帧后，在 Hierarchy 展开 **PVD Studio → Physics Scene → Actor → Shape**（缺少明确场景归属时显示 Unassigned）。选择刚体或单个形状，在 Scene 视图按 **F** 聚焦。Shape 的 MeshFilter 和 MeshRenderer 显示盒、球、胶囊、有限参考平面及捕获的三角网格表面。位姿更新时复用已有对象；形状的几何变化、刚体跨物理场景以及回放中的创建、销毁会同步到层级。这些临时对象用于编辑器查看。默认一录制单位对应一个 Unity 单位，可切换 X 轴镜像。真实地图的单位、坐标原点和上轴需与输入匹配。

在「叠加显示」中选择「面」（默认）或「线框」。面模式的「不透明度 (%)」默认是 16，适合对照游戏画面。斜视表面时轮廓颜色略强。拖到 0 可隐藏碰撞面并继续查看已开启的物理查询。点「原始实心」或拖到 100，使用当前管线的受光实心材质。暂停时也可调整，Hierarchy 中的选择会保留。

线框沿盒体的 12 条棱、平面的外框、球体和胶囊的圆环与经线，以及捕获网格的三角边绘制。在支持几何着色器的设备上，线条按屏幕像素展开并平滑边缘。贴面线条使用深度偏移，前方的实体仍可遮挡它们。其它设备使用原生细线。相同几何共享网格。

「视图与裁切设置」中的「在 Game 视图显示」默认关闭。勾选后，编辑器中的游戏相机会绘制同一帧的 PVD 形状，沿用所选的面或线框模式。两个视图共享同一组对象和网格。游戏相机按自身的层遮罩和视野绘制，包括输出到 RenderTexture 的游戏相机。取消勾选即可恢复只在 Scene 视图查看。

实时显示在后台读取选定帧。显示任务空闲后直接追到最新已发布帧。仅实时查看使用内存队列和最新场景状态。显示任务同步最新完整帧后，在自己的场景视图上裁切和生成显示数据。新增引用按增量同步，移除引用时共用接收线程已更新的列表。完整录制通过增量回放更新相邻帧，可暂停后移动裁切中心或拖动时间轴查看中间帧。

内置渲染管线通过相机回调切换根节点 LODGroup 的可见级别。组成员只在形状增删或组件重建时更新。SRP 使用 `beginCameraRendering` 和 `endCameraRendering`。自定义 SRP 需要触发这对回调，并在透明队列绘制 `SRPDefaultUnlit` 通道，才能显示半透明碰撞面和抗锯齿线条。

从 0.2.8 开始，三角网格与物体位姿分开传输。多个形状共享同一网格时，DLL 只发送一份顶点和索引，每个形状单独更新位姿和状态。连续查看同一范围时，已载入且仍有形状引用的网格可以跨帧复用。切换会话、切换物理场景或重新打开视图时，插件为当前画面重新加载所需网格。

单次传输上限为 32 MiB。新增网格数据与当前形状记录优先使用额度，物理查询使用剩余额度。当前显示范围内的唯一三角网格数据另有 128 MiB 缓存预算。核心在提取画面时也限制每次最多 100,000 个形状，以及按来源资源和缩放计算的 128 MiB 已解码网格。首次加载或一次引入大量不同网格仍可能达到上限，可以缩小显示的物理场景或裁切范围。

## 跟随物件显示附近形状

在 Hierarchy 选中物件，在 **Tools → PVD Studio → 视图与裁切设置** 点击「设为裁切中心」并设置「裁切半径」，默认是 20 个 Unity 单位。普通 Unity 物件使用当前的世界位置，即使全场景画面因超限无法打开也能设为中心。选中 PVD 刚体或其形状时，使用该刚体在当前回放帧的位置。点击「关闭裁切」可查看当前物理场景的全部形状。

物理场景筛选与半径可以同时使用。DLL 用空间索引查找附近的静态碰撞体，再判断形状是否与裁切球相交。较大的地形网格按空间分块提取附近的原始三角形，Hierarchy 中仍对应一个碰撞形状。完整录制与导出覆盖全部物理场景。

## 显示物理查询

在 **Tools → PVD Studio** 使用「显示物理查询」。默认开启，同时控制 PVD 捕获中的普通和批量射线、扫描（Sweep）与重叠查询（Overlap）。命中射线为红色，未命中为青色。胶囊、球、盒和凸体的扫描以蓝线显示轮廓与移动路径，重叠查询显示检测范围。重叠范围用紫线显示，命中的检测范围与可用的扫描命中标记用黄线显示。

查询随当前帧和所选物理场景更新，批量绘制并复用线网格。启用半径裁切后只显示裁切球内的线段。勾选「在 Game 视图显示」后，游戏相机也可绘制同一组查询。

发送端需要在对应的 PhysX 场景开启 `PxPvdSceneFlag::eTRANSMIT_SCENEQUERIES`。插件每帧最多显示 2,048 条射线和 8,192 段扫描与重叠查询线，超过显示预算时窗口会提示。全范围显示将超长射线与扫描画到距起点最多 10,000 个捕获单位，半径裁切按原始查询长度计算。

## 导出给桌面 Studio

在 **Tools → PVD Studio** 选择完整录制的会话，展开「导出与临时缓存」，点击 **导出选中会话（.pvdcapture）**，将文件保存到临时缓存之外的新位置。默认文件名包含 `unity-session-会话号` 和保存时间，可在保存窗口修改。插件在后台导出点击时该会话中全部可回放的完整帧，接收可以继续。当前显示的物理场景、暂停位置和面或线框模式不影响导出范围。

将导出的这一个 `.pvdcapture` 文件复制到另一台机器，在桌面 Studio 点 **打开** 即可回放。成功导出后可以清除会话临时缓存。长录制需要支持 PVDCAP04 的新版桌面 Studio。格式和限制见[分段导入与导出](retained-capture.md#分段导入与导出)。

## 缓存

0.2.3 在提交新帧前估算当前历史块的回放索引开销，包括类型定义、资源及其引用。共享资源在每块中只计一次。接近预算时，先封存已有帧，再将新帧放入下一块。同一个 TCP 会话继续录制，时间轴可跨块回看。单帧过大、运行中集中新增类型定义导致当前块超过预算，或磁盘空间不足时，录制仍可能停止并提示原因。

完整录制写入 `Application.temporaryCachePath` 下的 `PvdStudio` 子目录。网络分段用于吸收积压，磁盘历史用于逐帧恢复。查看器显示缓存总量、可清理量和清理结果。在窗口中清除缓存会回收符合条件的已结束会话。活动会话和当前查看的会话受保护。关闭查看后可再清理该会话。

## 验证

运行 `cargo test --locked -p pvd-core --test latest_scene` 核对最新完整帧发布与增量读视图，包括紧凑网格属性在引用编辑后的一致性。会话和表面帧使用 `cargo test --locked -p pvd-unity` 检查。对构建出的包执行以下命令，可验证压缩包内容、实际 DLL 加载、UTF-8 路径、TCP 接收、刚体世界位姿与形状局部位姿、物理场景归属、形状销毁与身份复用、倒序定位及缓存清理。参数也可以是展开的 DLL 路径。

```powershell
$unityPackage = '<分发目录>/com.pvdstudio.viewer-<版本>.tgz'
python tools/verify-unity.py $unityPackage --idle
python tools/verify-unity.py $unityPackage --live-only
python tools/verify-unity.py $unityPackage --measure
python tools/verify-unity.py $unityPackage --focus
python tools/verify-unity.py $unityPackage --rays
python tools/verify-unity.py $unityPackage --queries
python tools/verify-unity.py $unityPackage --display
python tools/verify-unity.py $unityPackage --long-live
python tools/verify-unity.py $unityPackage --portable --output <新文件.pvdcapture>
```

`--idle` 在已连接的实时模式和完整录制模式下检测空闲接收的 CPU 用量，再检查继续收帧和停止监听时关闭连接。

`--live-only` 连续发送 12,000 帧，检查最新完整帧、物理场景与查询、释放视图后重新读取、断开与重连、端口重绑，以及零磁盘缓存、旧帧和导出拒绝。

`--measure` 让 240 个形状共用一个含 8,192 个三角形的网格，并更新刚体位姿 24 帧。探针先用旧接口复现展开数据超过 32 MiB 的错误，再通过编辑器使用的新接口检查所有形状及其网格引用，输出首帧与后续帧的实际传输大小。

`--focus` 发送包含 40 个不同缩放网格的场景。探针先确认全场景超过 32 MiB，再验证移动世界坐标中心、跟随录制刚体回退帧、按物理场景筛选，以及同一局部网格跨请求复用。

`--rays` 发送两个物理场景中的普通和批量射线，检查命中标记、物理场景和半径筛选、逐帧更新、倒回以及每帧射线数量限制。

`--queries` 用夹具通过 TCP 发送胶囊、球、盒和凸体查询，检查扫描路径、重叠轮廓、命中、物理场景筛选、半径裁切、帧回退与线段预算。

`--display` 用一张 256×256 网格地形、2,400 个主要位于范围外的静态碰撞体与一个移动刚体，核对地形分块后的传输体积和顶点范围，以及当前帧重用、连续和间隔取帧、静态碰撞体移动及倒序定位。此网格达到紧凑数组阈值。脚本测量 DLL 取帧和复制传输数据的耗时。

`--long-live` 在一条 TCP 连接中创建 76,000 个静态几何对象，连续更新 6 个刚体，共发送 18,432 帧。脚本检查至少两次分块，通过分发 DLL 读取每个封存边界两侧的帧，检查刚体标识、位姿及形状，并在断开后再次读取末帧。输出包含封存范围、抽查帧号和缓存字节数，帧号从 0 开始。

在 Windows 的 PowerShell 7.3 或更高版本，以下两条命令分别加载展开包中的 C# 桥接和 DLL，用模拟的包变更通知与真实 TCP 客户端检查旧连接关闭、同一端口可重新绑定：

```powershell
./tools/verify-unity-package-change.ps1 <分发目录>/package -Change update
./tools/verify-unity-package-change.ps1 <分发目录>/package -Change remove
```

编辑器现场验收使用与当前地图匹配的真实捕获源，检查 Hierarchy 展开、选中与聚焦、受光表面与遮挡、Game 视图开关在实时和暂停时的效果、切图后重现当前帧、断开后回放及清理。分别用普通物件和 PVD 刚体设裁切中心，前者在暂停回放时移动，后者来回拖动 PVD 时间轴，确认附近形状会更新。用 Unity Profiler 的 Editor 模式，在同一地图和相机位置对比关闭视图、仅 Scene 显示、开启半径裁切、Scene 与 Game 同时显示及暂停时的主线程帧耗时与 GC 分配。单独核对场景保存、脚本重载和退出时的资源回收。

用含射线和形状查询的真实录制检查「显示物理查询」的默认值和切换效果。暂停时关闭开关应立即隐藏两类线条，重新开启应恢复当前帧的查询。开启 Game 显示或 X 轴镜像后，查询轮廓应与碰撞体对齐。在同一机位调整面不透明度，检查 0 时的查询、默认 16 时的场景纹理以及 100 时的实心遮挡。切到线框，检查贴地斜线和被前景物体遮住的线段。
