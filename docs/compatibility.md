# 兼容矩阵

参考目标为 NVIDIA PhysX Visual Debugger 3（PVD3）。主要验证路径为 PhysX 3.4.2，其他版本和数据类别单独记录。本文描述当前实现范围，既有测试身份见[验证说明](validation.md)，后续工作见[路线图](roadmap.md)。

## 证据与声明

- **真实验证**：对应 SDK 或 PVD3 的实际输出通过指定测试，只覆盖该输入和检查项。
- **代码路径**：已有解析或恢复实现及构造回归，尚不足以证明真实格式互通。
- **未建立证据**：缺少对应版本或类别的真实输入，不表示已经支持，也不自动表示缺少代码。
- 官方文档、共用源码、文件扩展名和单张图像不能替代实际兼容测试。

真实输入、原版二进制和符号不随源码提交；生产器、测试和验证方法保留。生成输入与配对要求见[验证说明](validation.md)。

## SDK

| 来源 | 已验证范围 | 未覆盖或限制 |
| --- | --- | --- |
| PhysX 3.4.2 | TCP/SDK 文件、动态对象/属性、几何、接触、查询、性能、内存、受控错误、回放；另有对象、Cloth、CPU 粒子、相机、OriginShift 专项 | 不代表全部类型、事件或原版文件兼容 |
| PhysX 4.1.2 | baseline/rich 文件与 TCP，位姿/生命周期、网格、样例接触/关节绘制、普通 Raycast、性能/内存解析 | 原版容器互通、完整分析语义、其他查询、ReducedCoordinate 等需独立适配和验证 |
| PhysX 3.0–3.3 | 集成文档与相关源码线索 | 未取得逐版本真实样例，不能继承 3.4 的通过结果 |
| PhysX 4.0、2.x 及其他版本 | 未建立实际兼容证据 | 需分别确定协议、类型及文件布局 |
| APEX / APEX Clothing | 参考资料中有相关工作流 | 未建立实际数据和完整支持范围 |
| GPU 粒子或其他 GPU 专用数据 | 未建立对应解释和真值 | Bevy 的 GPU 绘制不等于支持 PhysX GPU 数据类别 |
| OmniPVD / `.ovd` | 单独方向 | 不纳入 PVD3 格式实现 |

3.4.2 的固定 SDK 提交为 `5e42a5f112351a223c19c17bb331e6c55037b8eb`，4.1.2 为 `a2c0428acab643e60618c681b501e86f7fd558cc`。生产器和生成方法见 [3.4](../tools/physx-sample/README.md) 与 [4.1](../tools/physx41-sample/README.md)。

DEBUG、PROFILE、MEMORY 及接触/约束/查询等源端开关分别决定数据是否存在；工具不会模拟或补造未发送的信息。

## 文件与交换格式

| 方向 | 当前能力 | 边界与待验 |
| --- | --- | --- |
| SDK TCP | 3.4.2/4.1.2 接收、原始保存、重开和回放已验证；空连接不生成录制，非空截断仍报错；同监听器重连隔离有回归 | 本地回环及网卡绑定不等于真实跨机器场景验收；零字节连接不提供发送端未发数据的原因 |
| SDK 文件流 | 解析 communication stream，支持内存或桌面磁盘加载、完整流式分析和 SDK 裁剪 | SDK 直写 `.pxd2` 与原版数据库不同；一个已测文件被 PVD3 Open 拒绝，其原因未定位 |
| PVD3 数据库 v1 `.pxd2` | 已有三份真实保存文件配对，恢复受支持对象/属性/帧、分析、JointFrames、四类限位、RGB 三角形和一条无时间戳错误 | 512 MiB 导入上限；相机/显示设置未导入，未知历史/用户事件明确拒绝 |
| 原版初始快照与多页 | 非空 event=0 快照恢复、多页遍历、保存实例目录校验均有代码和构造回归；保存实例体已有真实结构对照 | 三份真实录制仍是空首快照/单页；非空首快照和多页整体配对未完成 |
| 原版 OriginShift | type 11 解码接入共同状态更新，有静态格式证据和构造反例 | 已有真实原版样例不包含 type 11，未证明该类容器互通 |
| 原版格式写出/裁剪 | 独立前缀实验可逐字节重建三份文件，并内部核对从 0 开始的前缀 | 未接正式入口，缺少 PVD3 打开/倒放/重存；任意中段和更广布局未完成 |
| 旧 `.pxd` / 过滤器中的 `.pvd` | 未建立格式和版本兼容证据 | 不按名字与其他容器等同 |
| 项目 `.pvdcapture` | 读取 `PVDCAP01/02`、写出 02；时间轴直接保存可用历史，含 TCP 接收中或原始流不完整时；重开及再次裁剪 | 保留原帧号；只保存仍可读取的范围，无完整原始字节，不提供 SDK 全源分析/裁剪或 PVD3 互通 |
| SDK 片段定义 | 最多 64 个范围，JSON sidecar 以完整源身份绑定；双遍流式导出、进度/取消/无覆盖发布 | 原版容器不提供此 SDK 导出；项目捕获不使用该 sidecar |
| RepX | PhysX 3.4.2 受支持刚体、基础/网格/地形几何、共享 Shape/资源和整帧六类官方关节，经 SDK 重读 | 特殊对象、单 Actor 关节依赖、运动学目标和其他 SDK 受限 |

原版读取证据见[文件格式](original-file-format.md)、[绘制](native-debug-draw.md)和[错误](native-errors.md)；写出实验见[前缀实验](native-prefix-experiment.md)。保存/导出边界见[项目捕获](retained-capture.md)、[片段](clips.md)与 [RepX](repx.md)。

| 曲线 | 多页/多曲线、标记、缩放、范围测量和跳帧 | 完整原生鼠标与剪贴板路径待验 |
| 界面 | 双语、停靠、紧凑工具栏与单行画面状态、退出实时原因、可隐藏并保存选择的播放/镜头操作提示、统计与详情分层、Windows 常规字体与 DPI 字号换算、叠加线宽与边缘平滑、选择联动、自由/轨道相机、坐标变换、过滤和焦点隔离 | 动态系统 DPI、全部停靠/IME、长期反复操作和资源趋势未全部验收；离屏布局不代替原生窗口验收 |

## 接收与性能声明

历史默认位于当前目录 `pvd-cache/history`，滚动上限 8 GiB。接收缓存、原始永久录制与回放历史独立，当前场景、分析和资源还有各自预算；这些值不是进程或 GPU 总内存上限。

真实回环的持续接收/回放与 OriginShift 各有独立验收记录，见[验证说明](validation.md)。这些测量不承诺任意输入下的硬延迟，也不代表跨机器负载或 PVD3 同条件性能对照。
