# 显示帧一致性

## 调度

`ui::prepare` 在 Bevy 场景同步前处理输入动作与异步结果；egui 绘制只读取该显示状态。完成的回放结果不会在同一轮布局重试中重复推进。

动作按输入帧和来源去重，最多 32 项，每条路径最多 128 KiB。关闭会话清空待执行动作，确认对话框使用独立状态。字体 atlas 在对应文字网格提取前发布，使纹理与字形 UV 属于同一轮输出。

## 分析视图

内存面板通过 `MemorySource` / `MemoryRows` 借用可见分配行，不先收集全量句柄。游标在候选状态中定位，成功后发布；失败保留可重试状态，不能显示为目标帧数据。

`SharedAnalysis` 统一 Resident 与 Legacy 视图，后端和所有权见[分页分析](resident-analysis.md)。隐藏面板在源变化时释放旧根、游标及异步结果。

## 验收

以真实 egui 按下/释放事件核对下一帧、播放、倒放、返回实时和关闭；即时图及连续序列需核对 UI/Scene 帧号、文本和 GPU 完成回执。

验收需覆盖无变化更新、合成边界、真实输入、持续 TCP 和可见模型的一致性。默认测试不能替代真实负载或完整窗口验收，已知问题见[验证说明](validation.md)。
