# 轨道与第一人称相机

在“显示设置 → 相机 → 控制模式”选择“轨道 / 第一人称”（English: Display settings → Camera → Controller → Orbit / First person）。默认轨道模式；模式和飞行速度随现有偏好保存。旧偏好文件缺少这些字段时仍使用轨道模式，飞行速度默认为10录制单位/秒。

视口左下角第一行提示空格播放/暂停、←/→ 逐帧与 F 聚焦；第二行提示当前相机模式的操作或录制相机说明。提示左侧的窄箭头可收起或展开，入口位置保持不变；悬停可查看用途，“显示 → 操作提示”提供相同开关，选择随偏好保存。开关不改变相机、所选对象或实时跟随。单击场景物体进行选择，双击聚焦。空格暂停实时显示时，TCP 接收和历史存储继续；再次按空格从当前位置正放，回到最新帧使用“返回实时”。倒放与首末帧使用播放栏按钮。

需要慢放时，先暂停实时画面，取消播放栏的“录制速度”，将帧率从默认 30 调低，例如 5 帧/秒，再点“播放”或“倒放”；最低 1 帧/秒。固定帧率同时适用于正放和倒放；实时跟随仍显示最新解码帧，不按该数值慢放，TCP 接收也不受其节流。手动逐帧使用左右方向键或上一帧/下一帧按钮。

## 操作与坐标

| 操作 | 轨道 | 第一人称 |
| --- | --- | --- |
| 在视口内按下右键并拖动 | 围绕观察目标旋转 | 保持眼睛位置，改变观察方向 |
| 按住上述右键手势 + WASD | 不移动相机 | 沿观察方向前后、横向左右移动 |
| 按住上述右键手势 + Q/E | 不移动相机 | 沿所选上轴下降/上升 |
| Shift + 移动键 | 不引入额外移动 | 速度乘2；斜向移动归一化，不叠加额外速度 |
| 中键拖动 | 在观察平面平移 | 在观察平面平移 |
| 视口滚轮 | 调整观察距离 | 调整飞行速度；底部提示显示当前录制单位/秒 |
| F / 查看全部 | 聚焦选中对象 / 适配捕获边界 | 同样可用 |
| Escape | 释放当前导航手势/焦点 | 释放当前导航手势/焦点 |

两种模式共用 `Viewport.target/yaw/pitch/distance`。切换本身不修改眼睛、观察目标或朝向；第一人称旋转后，观察目标位于当前前向、原观察距离处，切回轨道可连续地围绕该目标操作。飞行平移同时移动眼睛和目标。手动第一人称导航会解除对象跟随，滚轮仅调速时不会解除跟随；轨道的已有跟随行为保留。

位置计算在现有右手Y-up显示空间中进行，沿用源上轴/手性映射。飞行速度乘以“米/录制单位”得到显示空间每秒距离；Q/E沿映射后的显示Y轴移动，等价于沿使用者选定的源上轴移动。核心属性、录制及导出数值不变。相机没有碰撞、重力或物理模拟。

飞行速度限制为0.001–1e9录制单位/秒；旋转和平移沿用现有操作倍率。每次移动的时间步长限制在0–50ms，首个右键按下帧不移动，避免空闲或失去焦点后的长时间间隔造成跳跃。持续移动请求16ms后重绘；没有移动时不为飞行模式单独启动持续循环。真实空闲CPU和原生帧时间仍需独立测量。

## 输入归属

只有始于视口的右键按下才能激活导航，并由视口取得egui焦点。仅将已经按住的右键从其他控件拖进视口不会激活飞行。松开右键、Escape、窗口失焦、文本或其他控件取得键盘焦点、IME组字、模式切换都会使原手势失效；恢复后须重新在视口按下右键。松开右键也释放视口键盘焦点，其他面板的悬停滚轮不受残留焦点影响。Ctrl/Alt/Command组合键既不会被解释为飞行方向，也不会触发全局F、Space或左右逐帧快捷键。

文本焦点在帧开始时记录，并在处理视口输入前再次检查，避免同帧焦点变化把文本按键解释为导航。IME事件独立取消手势。视口自身持有焦点时，F、Space和逐帧左右键仍可用；它不被当作文本输入框。每个egui帧只应用一次移动，布局重算不重复积分。

全部输入测试只向隔离的 `egui::Context` 注入事件，不发送系统输入或创建窗口。

## 参考与验证

《PVD 3 User Manual》第 9 页描述自由相机、WASD 和 Shift 两倍速度，第 11–12 页列出控制器与轨道相机。本项目使用右键门控导航、Q/E 升降和单位/秒速度，不能把它与手册的单位/帧滑块直接等同。

自动化覆盖模式连续性、上轴/手性/单位、时间上界、斜向速度、焦点、IME、组合键和偏好迁移，向隔离 egui Context 注入事件。

```powershell
cargo test --locked -p pvd-desktop camera_controller
cargo clippy --locked -p pvd-desktop --all-targets -- -D warnings
```

先按 [SDK 说明](../tools/physx-sample/README.md)生成 rich 输入，再检查中英文离屏布局：

```powershell
cargo run --locked -p pvd-desktop -- --render-check captures/physx-3.4-rich.pvdstream output/camera-fly-zh.png 60 camera-fly 1440 960 --language zh-CN
cargo run --locked -p pvd-desktop -- --render-check captures/physx-3.4-rich.pvdstream output/camera-fly-en.png 60 camera-fly 1024 768 --language en
```

原生鼠标手感、系统 IME、DPI、屏幕边界连续旋转和原版操作对照仍需独立验收。相机不锁定或重置系统指针，到屏幕边缘后可松开右键重新定位。具名相机见[捕获相机](source-cameras.md)。
