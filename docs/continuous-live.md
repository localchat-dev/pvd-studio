# 持续接收与实时显示

接收、解码、历史提交和界面发布分别推进。TCP 连接与解码会话具有独立身份；旧会话的完成消息不能覆盖当前会话。

## 数据留存

| 数据 | 默认位置与生命周期 |
| --- | --- |
| 接收缓存 | 历史根下 `receive/`，按序交付后回收 |
| 回放历史 | `pvd-cache/history/`，完整临时录制加有界热缓存；已结束条目按清理策略保留 |
| 永久原始流 | 监听前启用自动录制，默认 `captures/`，独立保留 |

接收缓存默认无固定配额，256 MiB 积压告警；显式配额、至少 512 MiB 的可用空间保护和写入失败结束连接。协议字节不能通过丢弃中间事件降载。细节见[接收策略](receive-backpressure.md)。

## 显示与回放

界面跟随最新完成的解码帧，刷新率是目标上限，不代表发送端速度或实际窗口帧率。暂停与查看历史不停止接收；无效或同帧导航保持实时跟随。

完成帧以增量对象状态发布，界面复用树行、场景实体及共享几何。连续正倒放使用独立游标，按需分析不阻塞所有显示路径。默认完整录制先封存历史再释放热缓存，早期帧按需从磁盘读取；显式滚动模式才会移动可回放下界。

## 结束与错误

零字节连接不生成录制，监听继续等待。非空截断保留诊断和最后完成帧。完整原始录制在正常结束、解码收尾及刷新成功后发布为 `.pvdstream`，中断保留 `.partial`。

重连建立独立解码器、历史和原始文件，上一条已结束录制保留在临时列表。关闭活动录制先停止接收并处理已提交积压，再保留最后完整帧。临时缓存清理仅处理经标记、签名和租约验证的自有文件，未知内容与永久录制保持独立。临时条目的保存、清理及完整录制边界见[完整临时录制](temporary-recordings.md)。

时间轴可保存仍保留的历史为 `.pvdcapture`，无需预先开启原始录制。保存及原始流另存的格式范围见[保留捕获](retained-capture.md)。

## 验收

检查持续解码、积压排空、暂停与正倒放、过期恢复、重连隔离、取消和退出清理。协议构造测试与真实 SDK 回环分别记录，跨机器和长期负载仍需独立验收。当前结果见[验证说明](validation.md)，恢复机制见[共享历史](shared-history.md)。
