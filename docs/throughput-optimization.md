# 解码吞吐与诊断

处理成本分为字节解析、对象更新、分析维护、帧完成、历史提交和显示发布。接收字节、完成帧、GPU 完成与窗口呈现是不同指标。

## 数据路径

属性消息缓存参数名称、类型、偏移与继承布局，每个消息保留最近实际对象类型的编译结果。缓存最多 8 MiB，定义变化使其失效；状态需要空间时缓存退让。编译失败回到顺序解析，保持首错及已应用前缀。

历史写入使用借用序列化与不可变对象共享，避免完整中间副本。小记录缓冲最多保留 256 KiB，超限临时分配不常驻。发布顺序及磁盘边界见[共享历史](shared-history.md)。

## 采集

用 `start-with-diagnostics.cmd` 或下列参数启动，再在诊断页复制 JSON：

```powershell
.\pvd-desktop.exe --live-profile
```

详细计时默认关闭，包含计时自身开销。报告记录会话、计数、汇总时间与显示数量，不记录对象属性或原始流，也不自动上传。

| 指标 | 含义 |
| --- | --- |
| `decoder_input_bytes` | 已交给解码入口，不表示整个块已处理完 |
| `received_bytes` / `queued_bytes` | 同会话接收量 / 磁盘中尚未交付的数据 |
| `protocol_parse` | 字节解码与事件构造 |
| `builder_push` | 事件分派，包含对象、分析和帧处理 |
| `analysis_maintenance` / `analysis_ingest` | 分析维护 / 接入；接入可含写时复制 |
| `history_append` | 预留、编码、校验、写入和刷新 |
| `snapshot_publish` | 核心快照发布，不含界面消费或 GPU |

嵌套 inclusive 时间不能相加；跨版本比较父阶段时，先核对其定义是否一致。运行中计数不是原子快照，排队量也不包括已交付队列或正在解析的块。

## 验收

固定输入、分块、保留范围、配置和源码，分别记录普通运行与细分诊断。核心 API、持续 TCP 和端到端显示分别检查，见[实时吞吐](realtime-throughput.md)。
