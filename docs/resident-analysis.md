# 共享分页分析

`SharedAnalysis` 提供 Resident 与 Legacy 两种存储后端。SDK 实时解码和磁盘历史使用 Resident；原版容器及独立完整流扫描保留明确的 Legacy 路径。前端通过借用视图读取，不构造稠密影子分析。

## 不可变状态

性能区间使用共享分块序列，元数据、未闭合栈与存活分配使用路径共享树。完成根不可变；更新只复制受影响路径，显示快照可继续持有旧根。

同一会话的强引用、弱引用表、页恢复及草稿重叠在一个预算域中计量。192 MiB 域额度不是进程 RSS 上限。外部显示根不能为腾出空间而失效。

## 页面与身份

场景和分析页加入同一资源计划；依赖提交后才发布分析根、帧和目录。直接依赖由计划接管前，临时引用不能释放；失败或取消必须回滚未发布资源。

不可变文本和分配按来源身份及序号恢复共享，命中后校验内容。相同内容的不同身份不能任意合并。结构页缓存使用弱所有权；小子树复用需要复核树形、键、值和引用身份，不能延长源图寿命。

## 回放与消费者

连续回放保留最多 120 个完成分析根，范围内倒放直接切换根；窗口外从分页基线恢复。缓存仅另计元数据，页面负载由预算域统一收费。换源、取消和跨段恢复释放被替换的根。

性能与内存视图借用源状态，隐藏面板在会话变化时释放旧根和异步结果。完整序列化仍覆盖所有字段，用于 Scene/Analysis/Memory/Churn 的独立语义核对。

## 验收

验收覆盖完整及滚动历史、随机定位、正倒游标、保留旧根、预算压力、取消和清理。固定捕获专项需匹配输入，SDK 与 TCP 要求见[验收方法](acceptance-plan.md)。

失败尝试与测量保留对应输入身份；它们不替代[当前测试基线](validation.md)。页共享不保证磁盘整体缩小，也不保证冷定位或原生显示达到固定帧率。
