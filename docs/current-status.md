# 项目状态

pvd-studio 参考 NVIDIA PhysX Visual Debugger 3（PVD3）的功能与工作流程。主要验证 PhysX 3.4.2，PhysX 4.1.2 为部分支持，已独立核对地形、场景查询和 ReducedCoordinate 捕获中的 Base 关节树。

桌面提供 TCP 接收、[完整临时录制](temporary-recordings.md)、正倒/逐帧回放、对象检查、三维显示、性能与内存分析、曲线和录制导出。活动录制的早期历史封存到磁盘，不因热缓存回收而删除起点；已结束录制可回看、保存和清理。停靠布局、显示设置、帮助与快捷键说明可保存。

完整录制按新增历史成本触发封存，排除当前场景与分析写入器的固定预留，避免持续超软阈值造成逐帧重复封存。封存耗时可通过 `history_seal` 阶段单独诊断；容量保护与首帧保留规则继续执行。

程序退出支持中断事件处理及历史封存，并显示具体阶段和耗时；场景与界面缓存移交后台释放，临时历史文件后台删除。实际工作和永久写入结束后，清理宽限期为 2 秒，剩余带归属标记的临时数据留给后续安全扫描。普通关闭录制仍先处理已接收数据，见[退出与清理](temporary-recordings.md#退出程序)。

场景与对象树支持 Shift+单击多选，聚焦和显示范围覆盖选择集，属性及跟随使用当前对象；RepX 支持多个 Actor 及其依赖的合并导出。

[多物理场景调试](rooms.md)按 PxScene 代际稳定编号，界面显示“物理场景 1、2、3…”，原始身份在悬停详情中查看。提供场景列表、销毁/断开状态、显示隔离、相机记忆和回放联动。接收及录制仍覆盖整个会话；专项验收状态见[验证说明](validation.md#多房间)。

[NavMesh 叠加](navmesh.md)直接导入受限 Detour `MSET` `.bin`，各物理场景独立保存导航文件、透明度与对齐参数；支持全局图层、场景切换和全部场景显示，导入窗口居中打开。当前为小端、32 位引用、`MSET v1 / DNAV v7`；TileCache 暂不支持，真实游戏导出与同地图捕获的配对仍待验证。

[地面参考网格](coordinates.md)按视图射线绘制，无固定方形边界。平移保持世界坐标对齐，拉远自动显示更粗的格线，保留实体遮挡、单位换算和显示开关。

SDK 文件与 TCP 支持[帧来源选择](frame-sources.md)，回放沿所选 PhysX 或 APEX 来源进行。项目捕获写出 PVDCAP03 并保留来源目录，旧 01/02 仍可读取。APEX 1.4 CPU Clothing 的同步与异步文件、真实 SDK TCP 已核对同次 getter、生命周期、逐源绘制、回放和保存重开；实际画面通过无窗口检查。

PVD3 数据库 v1 支持分页读取、完整线程时间线、受限整份保存和区间裁剪；多 Scene 相机与内存组合、非空起点及再次裁剪有构造验证。[`.pvd` 录制包](pvd-archive.md)支持受限 ZIP32 读取，导出使用内部录制。原版应用互通、更广历史布局与真实多页/非空起点仍需验收，缺失前史保持明确标记。

RepX 支持已验证的刚体、六类官方关节、Articulation、混合 Aggregate、受限 CPU 粒子及运动学参数快照。对象、格式和不可恢复状态的范围集中维护在[兼容矩阵](compatibility.md)和[RepX 说明](repx.md)。
