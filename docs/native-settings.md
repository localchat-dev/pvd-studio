# 原版录制的相机与显示属性

PVD3 client database v1 的通信目录保存具名相机索引和实例显示属性。导入使用捕获中的类、属性和实例 ID，不推断 Scene、投影方式或视场角。

## 具名相机

相机索引为 `StringHandle → local instance ID`。对象类型为无命名空间的 `Camera`，包含 `Name: physx3::StringHandle` 和 `Origin / Up / Target: physx3::PxVec3`。原版 `setCamera` 在新建对象时设置名称，后续同名更新仅写三个向量的 36 字节属性消息；目录名称是稳定身份，不是逐帧重命名记录。

导入从初始快照和历史事件恢复这些值，接入与 SDK 流相同的具名相机选择和回放路径。完整帧记录相机状态；最后一个完整帧之后的更新不覆盖该帧。销毁实例会撤下对应相机，实例 ID 的新生命周期独立处理。撤下操作检查发布者和生命周期，保留其他发布者覆盖的同名相机。

对象 Name 为空而目录名非空时不发布相机；目录名也为空时，已知 Create 零初值及后续捕获向量仍进入状态。无效浮点向量保留为捕获数据，由视图检查能否使用。重复目录项、名称不一致、无效实例引用和不支持的布局会明确报错。

具名相机支持受限多 Scene 前缀、中段及派生非空起点再裁剪，稳定性能起点组合仍限单 Scene。保留历史创建、更新和销毁，不把末帧之后的视角写入末帧。布局、起点与撤销核验见[具名相机裁剪](native-export.md#具名相机裁剪)。

## 实例显示属性

通信目录中的 26 字节实例项包含源 ID、本地 ID、存在位、颜色及两个布尔值：

| 存在位 | 值 | 导入属性 |
| --- | --- | --- |
| `0x1` | 是否允许拾取 | `$pickable` |
| `0x2` | RGBA 四字节颜色 | `$color` |
| `0x4` | 是否列为顶层对象 | `$top_level` |

仅恢复存在位指定的值。这些是保存时的显示属性，没有变更时间，不能还原逐帧设置历史。明确标记为顶层的对象在对象树中独立列出，其子对象不继承该标志。

桌面按以下规则使用实例属性：

- 刚体实体及线框使用 Shape 自身的颜色；粒子和布料使用自身的颜色。没有颜色时使用状态配色。Actor 的颜色保留在属性中，不向 Shape 传递，也不沿 Scene 或父对象继承。
- 选中高亮优先于捕获颜色。捕获颜色的透明度与界面透明度相乘；界面的全部、已选或未选范围仍然有效。
- 状态配色可分别设置静态、唤醒、休眠、运动学刚体和布料；休眠状态优先于运动学分类。休眠筛选按 Actor 选择，触发器筛选按 Shape 或所属 Actor 选择，均支持全部、已选和未选。
- 空间拾取要求命中的 Shape 和返回的 Actor 均允许拾取。粒子、布料检查自身标记；未设置或类型不匹配时允许拾取。该标记不限制对象树选择、属性查看和聚焦。

这些是本项目明确的消费规则。原版元数据读取函数确认颜色为可选值、未设置的拾取标记默认为允许；原版渲染中的颜色优先级和跨对象继承尚未验收，不据此声称等效。属性缓存随可见实例更新和释放，引用解析检查实例生命周期；不同颜色的材质只保留当前显示使用的条目，数量受场景显示对象上限约束。

## 验证边界

布局依据 PhysX Visual Debugger 3 的保存、读取和相机更新代码，以及 PhysX 3.4 的数据类型定义。构造容器测试覆盖快照、属性消息、生命周期、内存与磁盘历史、连续正倒放和损坏输入；它们不替代原版保存的非空相机目录样例。此类真实样例的配对验收仍独立保留。

后台回归：

```powershell
cargo test --locked -p pvd-core native::settings
cargo test --locked -p pvd-core --lib native::export::camera
cargo test --locked -p pvd-core --lib native::export::middle::initial_source::tests::initial_analysis::multizone::cameras
```

裁剪专项覆盖原始字节、目录过滤、帧间更新/销毁、连续再裁剪、内存与跨分段磁盘正倒放、坏基线/撤销、预算及取消。性能组合专项区分单区、多区同事件号、后创建 Zone、相机起点与性能 Start 的撤销来源。手写输入的留存命令见[裁剪验证](native-export.md#验证)；默认不写文件。

桌面消费回归：`cargo test --locked -p pvd-desktop scene::captured_display -- --test-threads=1`，覆盖共享 Shape、正倒放、ID 复用、拾取穿透、材质释放、透明范围及点线实际绘制颜色；这些构造输入不替代原版渲染配对验收。
