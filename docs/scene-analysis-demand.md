# 场景与分析按需加载

场景游标和分析游标独立记录位置。场景定位恢复对象、属性、绘制、相机与错误；完整定位还恢复分析。同帧追加分析请求必须补齐数据，不能仅凭场景帧号相同返回。

## 桌面请求

连续播放请求场景。暂停后，内存面板、没有完整文件源的性能面板和待采样曲线按需请求当前帧分析。加载中或失败时显示状态，不把旧帧分析或空占位解释为当前结果。

初次打开磁盘录制时，流式解码末尾的分析不能用于首帧；定位成功才发布。没有完成帧时不请求不存在的第零帧。启播、循环和过期恢复从首步使用场景请求。

加载目标仍保留时可精确重试；已淘汰时提供最新可用帧入口。原画面保留到结果就绪，不自动反复换帧。完整文件查询和导出独立于显示位置，换源、关闭与退出则取消旧任务。

## 资源

场景模式仍读取并校验帧容器，省去完整分析恢复，不等于完全不读分析相关字节。同一次完整定位可复用相邻帧已校验输入，额外保留最多 1 MiB，超限回到读取路径，不跨调用缓存。

分析根共享与分页见[分页分析](resident-analysis.md)。首次、随机冷定位、场景应用及 GPU 各有成本，场景模式的 API 时间不能当作完整分析或窗口帧率。

## 原版依据与验收

原版静态调用关系显示连续正倒放可跳过分析刷新，暂停后再更新详情；这不能证明完整分析逐帧撤销。

回归覆盖非空分析、正倒放、暂停升级、加载时换帧/返回实时/关闭、淘汰重试及独立查询保留。受控 API 对照保留在 `scene-analysis-demand/controlled-1/`，测量只绑定对应源码和输入；当前验收见[验证说明](validation.md)。
