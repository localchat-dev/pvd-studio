# 逐项功能与验收清单

参考 NVIDIA PhysX Visual Debugger 3（PVD3）的手册工作流，保留稳定编号以便关联代码、计划与提交。具体 SDK/格式边界见[兼容矩阵](compatibility.md)，既有结果见[验证说明](validation.md)，后续任务见[路线图](roadmap.md)。

“已实现”描述代码能力，“部分支持”描述受限范围，“待验证”表示相关实现仍缺对应证据。任何单项通过均不表示全部 SDK、原版互通或所有原生交互验收完成。

## 手册对照

依据《PVD 3 User and Programmer Manual》12 页版本，SHA-256 为 `4e8e85de15987eb11ecf9a7a74330369283c395dc1db0cc41999cbfd3a0d116b`。页码为 PDF 页序，来源身份见[证据登记](evidence.md)。手册描述工作流，不定义完整文件格式或所有 SDK 行为。

| 手册页 | 范围 | 项目对应与差异 |
| --- | --- | --- |
| 3 | 实时捕获、对象历史和功能概览 | 主要功能类别有对应实现，具体范围如下表和兼容矩阵 |
| 4–5 | SDK 连接、直写文件和附加数据 | 主要验证 3.4.2；3.0–3.3 与 APEX 未建立支持。手册端口示例为 5435，项目默认 5425，连接双方须一致 |
| 6–7 | 文件、相机、导航和菜单 | 有定位、正倒放、目标/跟随及查看全部；原版保存覆盖、项目输出无覆盖，入口和布局不同 |
| 8 | 对象树与属性 | 动态属性、数组、引用、复制和曲线有实现；全部类型和原生操作未穷尽 |
| 9 | 三维显示与相机 | 有几何、查询及叠加；配色和选择手势不同，APEX Clothing 未支持 |
| 9 | 性能事件 | 有线程和事件视图、缩放与测量；原版首次出现排序和全部快捷手势未完全对齐 |
| 9–10 | 内存事件 | 有分配/释放和存活状态；手册 Churn 为本帧分配后尚未释放的内存，项目活动/净变化统计不能直接视为同一口径 |
| 10 | 错误流 | 有代码、位置和复制；原版多错误生命周期配对不足 |
| 10 | 片段操作 | SDK 与项目捕获可保存/裁剪；原版容器正式保存及任意区间裁剪缺失 |
| 10 | 线程分析与曲线 | 有线程分组、CSV、标记和跳帧；项目使用有界多图页，与原版每次绘图新建标签的方式不同 |
| 11 | 显示设置 | 有裁剪面、比例、过滤和手性；上轴只有六个固定方向，没有任意向量和自动判断，滑块范围/速度单位也不同 |
| 7、12 | 帮助与平台 | 帮助/关于/问题报告入口缺失；只交付 Windows x64，未继承手册的旧 Windows 与 macOS 支持声明 |

功能类别覆盖不等于操作一致或格式互通。差异分别关联下表、路线图 `PRODUCT-05` 与原版文件任务。
