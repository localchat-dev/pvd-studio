# 显示坐标系与单位

显示设置提供六个正负上方向、任意上轴向量、按重力自动判断、左右手系和“米 / 录制单位”比例。默认 +Y、右手、1；这是显示校准，不是源端物理单位声明。PhysX 的 tolerances scale 不能直接当作单位换算。

自定义上轴要求有限且非零，归一化后构造正交基。自动模式使用当前显示帧的 Scene.Gravity 反方向；选中 Scene 时优先使用该 Scene，否则各 Scene 的有效方向须一致。缺失、零重力、方向冲突或超过场景数量限制时提示原因并使用预设方向。暂停与历史回放不读取后台接收中的场景；Scene 索引随显示状态增量维护，设置未变时复用结果。

核心录制、属性、曲线 CSV 和 RepX 保留原始数值。只有 Bevy 展示层把录制坐标映射到右手 Y-up 的显示空间；相机目标输入使用源坐标，相机距离与裁剪面使用校准后的米。左右手转换在显示空间反射 X，保持选定的上方向。

- 几何全局姿态、局部姿态、网格、调试三角形使用同一正交基与统一缩放。镜像时反转三角形绕序，保留原顶点法线，经模型逆转置得到正确显示法线。
- SDK 调试点/线、关节轴和限位、接触、查询形状/路径/命中、质心、局部轴与速度箭头共用同一坐标映射。角速度作为轴向量处理，反射时包含基变换的行列式符号。
- Cloth 当前粒子先应用捕获的 Cloth 姿态，再进入同一显示映射；Fabric 约束使用这些粒子的世界位置。ParticleSystem/Fluid 已记录世界坐标，不再附加 Actor 变换。点标记半径使用录制单位，随统一比例换算；它不是SDK rest offset或流体表面。
- 拾取射线逆变换到录制坐标后与原始几何求交；命中距离再换算为显示空间距离，用于裁剪与最近表面比较。
- 聚焦、跟随、标签投影和观察目标使用一致映射。改变单位会同步换算相机距离与目标，原始属性不变。
- 地面参考网格位于显示空间 Y=0，按视口像素的射线与该平面求交绘制，无固定方形边界。网格原点始终对齐世界原点，近处以录制单位划分、每五格加深；远处按五倍单位逐级显示粗网格，过密细线平滑淡出，防止缩小时闪烁或整张网格消失。平移、转向及录制相机使用实际视图矩阵，不移动网格的世界坐标。显示单位比例统一换算间距；网格仍受近远裁剪和实体遮挡，并以独立深度偏移减轻共面竞争。红绿蓝原点轴分别标识源 X/Y/Z。参考网格不是从捕获推断出的物理地面，也不扩展导入的 NavMesh 数据。

包围盒、质心、Actor 局部坐标轴、速度和不透明度分别支持全部/已选/未选范围。Actor 选择作用于其 Shape；Shape 选择的包围盒与透明度只作用于该 Shape，其质心/速度仍属于 Actor。标记、速度箭头及关节坐标轴的尺寸可以独立调整；限位角度、几何和属性不随这些显示倍率变化。

Bevy 相机使用有限近/远透视矩阵，保留现有 Bevy 渲染和子视口投影基础设施。有效配置必须满足 `0 < near < far` 且数值有限；非法输入不替换已生效的配置。反向深度中近面映射到1、远面映射到0，矩阵同时约束两端；标签和拾取使用相同显示空间裁剪距离。数值测试核验这些边界，当前GPU图核验矩阵接入；远面边界逐像素深度验收仍待完成。

自动化覆盖按实际范围区分：

- 位姿组合与坐标往返：六个上方向 × 两种手性 × `0.001`、`1`、`1000` 三个单位比例；另核对轴向角速度、镜像法线与绕序。
- 相机投影、表面拾取、聚焦与网格朝向：六个上方向 × 两种手性 × `1e-6`、`0.001`、`1`、`1000`、`1e6` 五个单位比例；标签与拾取裁剪另有边界测试。
- 辅助网格：数值专项与 GPU 图片分别检查地面交点、世界单位对齐、近远裁剪、不同单位比例、显示开关及恒定渲染资源；大范围平移、远距离缩放、接近地平线、地下观察、向天空观察和倾斜录制相机使用离屏场景检查。
- 有限透视矩阵：上述五个比例的近/远边界、边界外拒绝；尺寸变化、子视口像素一致性与非法配置保留。
- 点云：+Z/左手在 `1e-6`、`1`、`1e6` 下的坐标、可见性、深度与对象选择逻辑。
- 任意上轴：非轴对齐向量、极大/极小有限值、无效值拒绝、手性与单位组合、源相机投影与拾取；自动模式覆盖 Scene 生命周期、重力冲突、缓存与暂停画面。

无窗口渲染需同时检查实体、包围盒、关节轴/限位、RGB 三角形、Cloth 点/约束和粒子，确保坐标映射一致。Cloth 无表面拓扑的来源限制不能由图片补足。

这些图证明相应捕获的绘制接入与布局，不等同于远面边界逐像素验收，也不扩大为Cloth/粒子所有坐标组合的GPU测试。近远边界仍以五尺度矩阵测试为证据；所有原生输入验收仍单列。

```powershell
cargo test --locked -p pvd-desktop coordinate
cargo test --locked -p pvd-desktop camera_projection
cargo test --locked -p pvd-desktop infinite_grid
cargo test --locked -p pvd-desktop point_clouds_follow
./target/debug/pvd-desktop.exe --render-check captures/physx-3.4-joint-limits.pvdstream artifacts/desktop-coordinates.png 4 coordinates-z-left 1440 960 --language zh-CN
```

网格运动检查固定捕获帧，输出目录须尚不存在：

```powershell
./target/debug/pvd-desktop.exe --render-check captures/physx-3.4.pvdstream output/grid-motion 0 grid-motion 1024 720
```

检查输出 34 张纯三维图片与 `grid-motion.json`，覆盖平移、缩放、转向、地面显隐、零/负深度偏移和远裁剪面；另外检查平移 10,000 单位、观察距离 500/5,000、低俯角、地下、向上观察、倾斜录制相机及关闭网格。可加 `--no-line-aa` 并使用不同目录检查关闭抗锯齿的路径。数值测试不能代替 GPU 图片检查，已验姿态不作为所有设备及姿态的闪烁保证。

无限网格资源/开关、有限投影和 NavMesh 回归已通过；34 个 GPU 场景在 AMD Radeon RX 6700 XT / Vulkan 上完成，并检查代表画面。开启/关闭网格时不透明物体内部像素一致，仰视天空无网格，另已检查 PhysX 与 NavMesh 的组合画面。

自动模式采用本项目明确的 Gravity 规则，原版的确切自动算法尚未建立证据。每个 Scene 单独设置坐标系、原版坐标设置视觉对照及原生鼠标操作未验收。转换测试不能证明捕获源实际采用哪种手性或单位；设置值由使用者确定。
