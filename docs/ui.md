# 桌面界面

界面使用 Bevy 与 egui，展示来自捕获。用户操作见 [Windows 使用说明](distribution.md)，功能边界见[兼容矩阵](compatibility.md)。

## 布局

顶部第一行是文件、TCP 状态和监听操作，第二行是回放控制和帧号。右上角设置集中提供连接、历史、录制、语言及布局选项。对象树位于左侧，场景居中，属性和显示设置位于右侧，时间轴与分析页位于下方。

场景状态使用绿色实时、琥珀色暂停/定位、蓝色正放/倒放。实时跟随最新解码帧；接收仍可能落后于发送端。接收积压、源端停帧、无效导航和同帧导航不会自行取消跟随。暂停原因、最新解码帧及落后帧数按需显示。

常驻统计只显示刚体、唤醒、休眠、运动学和静态分类；SDK 活动数及口径放入悬浮提示，缺失值保持未知。时间轴显示帧号、保留范围、容量、保存及导出；详细接收和解码信息放入诊断页。

## 操作

| 输入 | 操作 |
| --- | --- |
| 空格 | 播放/暂停；返回实时使用独立按钮 |
| 左右方向键 | 前后逐帧 |
| 单击 / 双击几何 | 选择 / 聚焦 |
| F | 聚焦选中对象 |
| 轨道相机右键拖动 / 中键拖动 / 滚轮 | 旋转 / 平移 / 缩放 |
| 第一人称按住右键，WASD / Q、E | 水平移动 / 沿上轴升降 |
| Shift / Esc | 两倍移动速度 / 释放导航 |

第一人称速度按录制单位/秒计算，滚轮调速。文本编辑、其他控件焦点及 IME 组字期间不处理视口快捷键。左下角两行操作提示可用固定箭头折叠柄或“显示 → 操作提示”开关，状态随偏好保存。

慢放先暂停实时，关闭“录制时序”，调低播放帧率后正放或倒放。播放帧率不限制接收速度。

## 显示与输入一致性

`ui::prepare` 在场景同步前应用输入动作和完成的异步结果，绘制读取同一显示状态。字体纹理在对应文字网格提取前发布。详见[显示帧一致性](display-frame-consistency.md)。

场景通过离屏纹理嵌入 egui，最长边为 4096 像素，超限时等比例缩小。显示、标签与拾取共用投影和坐标变换。几何、Cloth/粒子点及绘制预算超限时报告诊断，捕获本体保持完整。

叠加线宽默认为 1.25 物理像素，可调 0.5–4 px；线边缘覆盖与 4× MSAA 共用原三维深度路径。`--no-line-aa` 用于同线宽对照，着色器来源与许可证见 [vendor 补丁](../vendor/bevy_gizmo_lines/PVD-STUDIO-PATCH.md)。

## 字体与偏好

Windows 常规字体为 Segoe UI、Microsoft YaHei UI，等宽数值用 Consolas；不可读取时回退到 egui 字体和黑体。正文 15、辅助文字 13、对象编号 12 逻辑像素，按 DPI 渲染。

中英文只改变界面文本，保留 SDK 名称、属性、捕获文本及 CSV 字段。控件身份独立于译文。布局和偏好写入 `%LOCALAPPDATA%/pvd-studio/layout.json`；布局校验失败或 panic 展开时不覆盖有效偏好。停靠仅在一个系统窗口内进行。

## 保存与资源

时间轴保存磁盘历史为 `.pvdcapture`，内存 SDK 文件保存原始 `.pvdstream`；完整原始流另存独立。默认目录为 `captures/`，输出暂存、同步后无覆盖发布。范围和格式限制见[保存说明](retained-capture.md)。

窗口、停靠与线条补丁固定在 `vendor/`，来源和许可证保留。库版本由 Cargo 配置和锁文件确定。原生输入、DPI、文件选择器及长期负载的验收范围统一见[验证说明](validation.md)，与 PVD3 的操作差异见[手册对照](manual-checklist.md)。
