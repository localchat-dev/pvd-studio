# 桌面界面

界面使用 Bevy 与 egui，展示来自捕获。用户操作见 [Windows 使用说明](distribution.md)，功能边界见[兼容矩阵](compatibility.md)。

## 布局

顶部提供文件、TCP 状态、监听操作和帧来源。右上角设置集中提供连接、历史、录制、语言及布局选项。对象树和属性区分列两侧。场景、时间轴和分析页使用中栏，左右两侧可各自使用完整高度。

时间轴集中提供正倒放、跳帧、速度和返回实时。回放状态区同时显示当前画面与待定位帧。时间轴未选中、已收起或浮动时，回放控制会出现在顶部工具栏。

拖动标签可排序、分栏或在主窗口内浮动；右键标签可关闭面板，在“设置 → 面板”中恢复。场景面板不可关闭。隐藏状态、顺序和浮动分组随布局保存；打开曲线、诊断等目标页时自动恢复并展开所在分组。“重置布局”恢复全部面板，不改变录制与回放状态。

场景状态使用绿色实时、琥珀色暂停/定位、蓝色正放/倒放。实时跟随最新解码帧；接收仍可能落后于发送端。接收积压、源端停帧、无效导航和同帧导航不会自行取消跟随。暂停原因、最新解码帧及落后帧数按需显示。

常驻统计只显示刚体、唤醒、休眠、运动学和静态分类；SDK 活动数及口径放入悬浮提示，缺失值保持未知。时间轴显示帧号、保留范围、容量、保存及导出；详细接收和解码信息放入诊断页。

诊断页优先显示错误记录，起点已有错误单独列出；内存用量、导入限制和应用日志可按需展开。

## 操作

| 输入 | 操作 |
| --- | --- |
| 空格 | 播放/暂停；返回实时使用独立按钮 |
| 左右方向键 | 前后逐帧 |
| 单击 / 双击几何 | 选择 / 聚焦 |
| Shift+单击几何或对象树 | 增减所选对象 |
| F | 聚焦全部所选对象 |
| F1 | 打开操作说明 |
| 轨道相机右键拖动 / 中键拖动 / 滚轮 | 旋转 / 平移 / 缩放 |
| 第一人称按住右键，WASD / Q、E | 水平移动 / 沿上轴升降 |
| Shift / Esc | 两倍移动速度 / 释放导航 |

第一人称速度按录制单位/秒计算，滚轮调速。文本编辑、其他控件焦点及 IME 组字期间不处理视口快捷键。左下角两行操作提示可用固定箭头折叠柄或“显示 → 操作提示”开关，状态随偏好保存。

对象搜索接受名称、类型及十进制或 `0x` 十六进制 ID。输入当前帧存在的完整 ID 后按 Enter 选择，按 F 聚焦。数组项与普通属性使用相同的枚举、标志位和数值格式；右键属性或已展开的数组元素可复制、添加数值曲线。菜单打开后若切换录制、对象代际或元素类型变化，操作失效，须重新选择目标。

多选时，属性与跟随使用当前对象，高亮、显示范围和聚焦使用全部所选对象；新增项成为当前对象。普通单击替换选择，Shift+单击增减单项，最多 4096 项。回放中已销毁或换代的对象会移出选择，新录制清空选择。RepX 可导出所选受支持 Actor 及共同依赖，任一对象不满足要求时整体报错。

“显示 → 相机”中的“重置相机”将目标移到场景边界中心，保留观察距离；“查看全部”同时调整距离以容纳场景。

慢放先暂停实时，关闭“录制速度”，调低播放帧率后正放或倒放。接收速度独立于回放帧率。

顶部“帮助”提供操作说明、版本/构建信息及问题反馈模板。帮助弹窗隔离相机输入，打开和关闭不改变实时、暂停或播放方向；Esc 可关闭。反馈模板包含版本与帧数等基本状态，不包含录制路径，也不会自动发送。

## 显示与输入一致性

`ui::prepare` 在场景同步前应用输入动作和完成的异步结果，绘制读取同一显示状态。字体纹理在对应文字网格提取前发布。详见[显示帧一致性](display-frame-consistency.md)。

场景通过离屏纹理嵌入 egui，最长边为 4096 像素，超限时等比例缩小。显示、标签与拾取共用投影和坐标变换。几何、Cloth/粒子点及绘制预算超限时报告诊断，捕获本体保持完整。

叠加线宽默认为 1.25 物理像素，可调 0.5–4 px；线边缘覆盖与 4× MSAA 共用原三维深度路径。`--no-line-aa` 用于同线宽对照，着色器来源与许可证见 [vendor 补丁](../vendor/bevy_gizmo_lines/PVD-STUDIO-PATCH.md)。

捕获的调试三角形按三条边显示，各边使用起点的 RGB；点和调试线不以捕获颜色的 alpha 混合。原始 ARGB 保留在数据与导出中，不按 APEX 枚举替换颜色。这一显示规则依据 PVD3 的三角形提交与无混合线条路径，最终像素仍受抗锯齿、深度和色彩空间影响。仅含调试绘制的场景也支持“查看全部”和按绘制关联对象聚焦。

## 字体与偏好

Windows 常规字体为 Segoe UI、Microsoft YaHei UI，等宽数值用 Consolas；不可读取时回退到 egui 字体和黑体。正文 15、辅助文字 13、对象编号 12 逻辑像素，按 DPI 渲染。

中英文只改变界面文本，保留 SDK 名称、属性、捕获文本及 CSV 字段。控件身份独立于译文。布局和偏好写入 `%LOCALAPPDATA%/pvd-studio/layout.json`；布局校验失败或 panic 展开时不覆盖有效偏好。停靠仅在一个系统窗口内进行。

## 保存与资源

时间轴的「保存与导出」提供整段录制、原始流、录制片段和当前帧 RepX。磁盘历史保存为 `.pvdcapture`，内存 SDK 文件保存为原始 `.pvdstream`。默认目录为 `captures/`，输出暂存、同步后无覆盖发布。范围和格式限制见[保存说明](retained-capture.md)。

窗口、停靠与线条补丁固定在 `vendor/`，来源和许可证保留。库版本由 Cargo 配置和锁文件确定。原生输入、DPI、文件选择器及长期负载的验收范围统一见[验证说明](validation.md)，与 PVD3 的操作差异见[手册对照](manual-checklist.md)。
