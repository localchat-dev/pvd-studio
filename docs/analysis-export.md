# 完整录制的分析 CSV

桌面性能和内存面板提供整份录制的 CSV 导出，独立于当前显示帧及分析窗口。SDK 输入可以是内存加载或磁盘加载的完整 `.pvdstream` 文件；监听需已停止。CLI 的 `profile-csv` 和 `memory-csv` 使用同一流式实现。原版容器使用共同的 `write_analysis_csv`：内存输入读取完整分析，磁盘输入遍历持久帧根及末帧之后的分析；格式边界见兼容矩阵。

| 命令/入口 | 每行含义 | 不包含的其他数据 |
| --- | --- | --- |
| `profile-csv` / 全部完成区间 | 一个已配对 CPU 性能区间，保持捕获接收顺序与原始时间戳 | 未结束区间、未匹配结束、数值事件和 CUDA 负载不是区间行；摘要保留相应计数 |
| `memory-csv` / 全部内存汇总 | 收到一个内存事件缓冲后的累计分配、释放、存活字节及存活数量 | 不是每个分配/释放一行，不替代内存事件明细 |

范围是完整文件，`received_frame` 仍表示已接收的完成场景帧数；它不是事件所属 Scene，也不是事件发生时刻。CPU 嵌套区间允许重叠，不应把行时长总和当 CPU 利用率。

## 处理与资源边界

核心入口为 `analysis_export::export_analysis_csv_streaming`。第一遍完整解码并收集最终 zone/event 名称；第二遍按批次输出 CSV，保留跨缓冲嵌套起点、字符串、常驻分配及累计计数，及时释放已输出的历史。两遍完整文件的 BLAKE3、大小和帧数必须一致。它不使用实时窗口裁剪，也不依赖完整 Recording 的总文件或历史事件数量限制。

当前场景/元数据及分析当前态仍有预算，开放区间、常驻分配和字符串不能无限增长。未知分析事件、截断、未提交属性事务、状态超预算、源变化、输出失败或取消都返回失败；不会因实时显示仍能继续而把不完整 CSV 报为成功。CUDA kind 6 仅按既有语义识别和计数，不表示已解释其负载。

CSV 保持现有列格式。性能行使用最终元数据名称；同一 ID 改名时摘要明确报告歧义。名称并不是精确事件键，精确区分仍需 zone/event/thread/context 数字键。

内存路径拒绝只剩保留窗口的分析；原版磁盘路径要求所有帧根完整，两遍读取每帧新送达的记录及录制末尾刷新，当前分析窗口的裁剪不影响完整输出。任意非空原版初始快照都缺少可证明完整的分配前史，完整内存 CSV 在写入前拒绝；已有[来源总量](memory-history.md#原版来源总量)不能补齐这些事件。分析解码中止、帧根缺失或取消也返回失败。一般原版兼容范围诊断仍保留，导出不增加对原版未导入数据的支持。原版导出显示行数进度，SDK 双遍导出显示字节进度。

桌面导出与片段导出共享有界后台任务。磁盘源会与打开时的完整身份核对；关闭录制或换源请求取消并丢弃晚到界面结果。原版导出持有当前已加载录制，不在后台重新读取可能改变的源文件。输出在同目录暂存、同步后无覆盖发布。关闭应用时取消导出并等待临时文件清理，包含已从界面移除的旧任务；完整原始录制的另存也使用此退出等待与分块取消。强制结束进程可能留下暂存文件；已经发布的文件不会被取消回滚。

Windows CLI 的流式导出已接 Ctrl-C / Ctrl-Break 协作取消，检查/写入循环及最终发布前检查取消标记。真实隔离控制台测试覆盖五种检查/部分写出时中断，均无正式文件或临时残留。Unix 处理入口已实现但尚未在该平台实测。

## 验证

先生成 [SDK ALL 输入](../tools/physx-sample/README.md)，再执行：

```powershell
cargo test --locked -p pvd-desktop recording_export::tests
cargo run --locked -p pvd-cli -- profile-csv captures/physx-3.4-all.pvdstream output/full-profile.csv
cargo run --locked -p pvd-cli -- memory-csv captures/physx-3.4-all.pvdstream output/full-memory.csv
```

输出目录需存在，目标文件不能已存在。核对行数、精确键、时间戳和未配对计数；桌面磁盘与内存导出使用相同输入，与明确的参考版本比较。原版输入与参考 CSV 的准备见[原版验证](native-validation.md)。

发布回归覆盖两阶段取消、源身份失配和完整发布，退出测试确认暂存清理后才退出。这些检查不替代原生窗口交互或任意规模输入的验收。
